Waystones — publish GeoPackage and PostGIS data as OGC API services

Waystones is an open-source, in-browser tool for geospatial data models. Drop in a GeoPackage or connect PostGIS or Supabase, refine the data model, and get a ready-to-run service stack: OGC API Features, WMS, vector tiles (PMTiles) and a STAC catalog.

  • Infer a data model from a GeoPackage, PostGIS, Supabase, GeoJSON or an OGC API
  • Edit layers, fields, code lists, relations, styling and metadata
  • Export deploy kits for Docker Compose, Railway and GitHub Codespaces, or deploy to Waystones Cloud
  • Free and open source under the AGPL-3.0 licence
